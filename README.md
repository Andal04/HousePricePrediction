***House Price Prediction***

A machine learning project to predict house prices using various regression models. This project is based on a dataset with 79 explanatory variables describing different aspects of residential homes.

***Project Objective***

To build and compare regression models that can accurately predict the selling price of houses based on features like location, size, condition, and amenities.
- Target: `SalePrice`

***Workflow***
1. Data Loading & Cleaning  
2. Exploratory Data Analysis (EDA)  
3. Feature Engineering & Encoding  
4. Model Building & Evaluation  
   - Linear Regression  
   - SVR, XGB, Random Forest, etc.  
   - Metrics: RMSE, R² score  
5. Performance Comparison & Final Model Selection  

***Models Used**

The following regression models are built and evaluated:
- Linear Regression
- SVM Regressor
- KNN Regressor
- Random Forest Regressor
- XGB Regressor
- Model Evaluation: Compared models using RMSE and R² Score

***Tools & Libraries Used***
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook
